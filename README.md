# 巨兽急诊班 / GUT CREW

一个使用 Godot 4 开发的四人合作动作游戏原型。四名巴掌大小的体内维修工被吞进巨大生物体内，在活体器官中诊断疾病、清洁病灶、修复组织、对付寄生虫，并想办法逃离病患身体。

> 当前仓库处于持续开发阶段。本地玩法与自动化测试已验证，正式四客户端联机同步仍在完善中。

## 核心特色

- 手工黏土、定格动画风格，整体 80% 可爱、20% 微恶心。
- 第一/第三人称切换，移动、跳跃、冲刺、闪避和完美闪避。
- 四个固定职业拥有不同的左右键攻击、Q/E 技能与组合连携。
- 胃酸潮、胃部痉挛、吞咽水流等动态身体事件。
- 诊断、清洁、治疗、搬运、追鼠、护送与巨型猫最终战。
- 胃酸池钓宝、战利品回收、BioCoins 与局内职业强化。

## 四个职业

| 角色 | 急诊分工 | 战斗方向 |
|---|---|---|
| 闪仔 Spark | 神经诊断、设备供能 | 高频电弧、闪电位移、导电标记、范围麻痹 |
| 咔咔 Kaka | 异物搬运、结构固定 | 骨钉蓄力、骨钩、长骨、冲撞 |
| 泡泡 Bubble | 冲洗、消毒、清洁 | 蓄力滚动、弹跳落地、诱饵、包裹喷射 |
| 菇菇 Shroom | 菌疗、组织修复 | 孢子、傀儡控制、菌毯、发酵爆发 |

## 操作

- `WASD`：移动
- `Shift`：冲刺
- `Space`：跳跃
- `Ctrl`：闪避
- `LMB / RMB`：职业攻击
- `Q / E`：职业技能
- `F`：诊断、清洁、治疗、搬运、钓宝及购买
- `1 / 2 / 3 / 4`：切换职业
- `Tab`：切换第一/第三人称
- `Esc`：暂停与菜单

## 运行

1. 安装 **Godot 4.7.2 stable**。
2. 用 Godot 打开根目录的 `project.godot`。
3. 运行主场景，或调整 `GUT_CREW_GODOT_PLAY.bat` 中的 Godot 路径后启动。

本仓库不会提交 Godot 编辑器程序、`.godot` 缓存、本地备份或 QA 截图。

## 自动化测试

Windows 下运行：

```bat
QA_GODOT_PHASE27.bat
```

## 当前故事

首个病例是收容所猫咪 Mochi。急诊班从猫嘴进入，穿过胃部与器官区域，调查它吞下电子老鼠的原因。解决体内问题并逃离后，队员还要面对被电子老鼠惹怒的巨型猫，而病例的真相会在结尾揭晓。
